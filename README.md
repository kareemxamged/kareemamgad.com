## 🏛️ Executive Summary & Anti-AI-Slop Manifesto

Most developer portfolios today suffer from **"AI Slop"**: generic purple-to-pink gradient blobs, cookie-cutter cards, unverified claims, and zero proof of business impact.

This digital headquarters was engineered with **Linear / Raycast tier precision** to reflect how a modern **10x Systems & Growth Operator** works:
- **Obsidian & Zinc Minimalism**: High-contrast OLED dark palette (`#09090b` / `#121215`) with precise micro-borders (`border-white/[0.08]`) and emerald telemetry accents.
- **Micro-Interactions Over Gimmicks**: Native Framer Motion springs, interactive state machines, and hardware-accelerated transitions that respond instantly without sluggishness.
- **Verified Proof-of-Work**: Real production repositories, verified live client domains, official government scholarship PDFs, and authenticated Meta Coursera credentials.
- **Full-Spectrum Responsive Design**: Engineered and tested from **360px** (iPhone SE) to **4K** screens with zero horizontal overflow and Apple/Google-standard touch ergonomics (`>= 44px`).

## 🚀 Getting Started & Local Development

### Prerequisites
- Node.js 18.18+ or Node.js 20+
- npm, pnpm, or yarn

### 1. Clone the repository
```bash
git clone https://github.com/kareemxamged/kareemamgad.com.git
cd kareemamgad.com
```

### 2. Install dependencies
```bash
npm install
# or
pnpm install
```

### 3. Start development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

### 4. Build for production
```bash
npm run build
npm run start
```

## 🌐 Deployment Guide

### Deploy to Vercel (Recommended)
The fastest way to deploy this portfolio is using the [Vercel Platform](https://vercel.com):

1. Push your repository to GitHub.
2. Import the project into [Vercel](https://vercel.com/new).
3. Vercel automatically detects Next.js:
   - **Framework Preset**: Next.js
   - **Build Command**: `npm run build`
   - **Output Directory**: `.next`
4. Click **Deploy**.

Alternatively, deploy using the Vercel CLI:
```bash
npm i -g vercel
vercel --prod
```

### Deploy to Cloudflare Pages
1. In Cloudflare Dashboard, go to **Workers & Pages** → **Create application** → **Pages** → **Connect to Git**.
2. Select repository and set framework preset to **Next.js**.
3. Deploy!
